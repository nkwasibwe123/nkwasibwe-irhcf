Build sequence and release gates

We will deliver the system in verified layers: authenticated data model → profiles and social graph → posts/feed → persistent messages → realtime → safe media storage → video/creator tools → professional features → security and Android end-to-end tests. External platforms will only be connected through documented APIs and user-authorized account linking. “Phoenix” still needs identification (product name or URL) so its features can be mapped accurately.
